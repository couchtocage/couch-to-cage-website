# Request-only notifications hotfix

- Admin Notifications now shows only completed requests that CTC sent to fighters.
- Weight and bloodwork request responses are separated into their own boxes.
- Same-fighter responses remain grouped.
- Search by fighter is retained.
- REVIEWED removes a notification from the admin request center without deleting the underlying fighter/request history.
- Messages stay in Messages, bloodwork review stays in Bloodwork, and normal fighter activity no longer appears here.
- Main admin navigation was rebalanced and the More button widened to remove the oversized gap.
- No database migration is required for this hotfix.
